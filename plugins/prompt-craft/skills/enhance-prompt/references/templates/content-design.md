# 内容与设计

适用于选题、文案、视觉设计或生图请求，只取适合该任务的字段。复用已有信息，不要求逐项填满，也不默认营销用途或增长指标。

## 补漏字段

- 受众与用途：给谁看、用在何处、希望表达什么？保留用户已经确定的场景。
- 素材与事实：现有文字、图片、产品资料和参考；不把参考当成用户拥有的素材或已确认事实。
- 风格：保留用户原词、品牌约定与明确禁忌，不擅自追加配色、字体、版式或语气标签。
- 交付：是选题、提纲、草稿、成稿、设计方案还是图像？保留用户指定的数量、格式与完成程度。
- 选择与缺项：关键创作方向缺失才澄清；可由执行者决定的细节不转为用户硬要求。
- 核对：内容符合用途与素材条件，表达保留原意；涉及事实的内容有依据。

## 整理方式

按“受众用途 → 已有素材 → 风格与限制 → 交付程度”组织请求。只要选题就停在选题；内容创作不自动授权发布或外部发送。

## 示例

原始想法：给宠物洗护店想几个小红书选题，给本地养狗的人看。只有门店照片和洗护前后照，不露脸，先要选题。

增强结果：为宠物洗护店构思几个面向本地养狗人群的小红书选题，围绕现有门店照片和洗护前后照展开，保留不露脸的要求。本次只给选题。
